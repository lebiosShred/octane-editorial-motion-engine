# Master Asset Lifecycle Playbook: Research, Generation & Placement

The definitive 3-stage protocol for engineering high-retention editorial motion graphics with zero AI slop.

---

## 🏛️ Stage 1: Domain Telemetry Research Protocol

Before writing a single line of React code or animating a frame, you must rigorously research the subject domain:

1. **Deconstruct Canonical System Entities**:
   - Extract real architectural components (e.g., dimensions, process scripts, rule engines, memory registers, execution pipelines).
   - Banish generic placeholders like "Data Box" or "Server 1". Use real identifiers (e.g., `Dim_Product`, `Control_Feeder_Flags`, `0x7FFF4E20`).

2. **Compute Mathematical Calculation Explosions**:
   - Every metric on screen must be mathematically grounded.
   - Example: 15,000 SKUs × 200 Stores × 36 Periods = 108,000,000 Fed Cells.
   - Use `computeDimensionalExplosion()` to verify scaling logic.

3. **Cognitive Tension vs. Resolution Dynamic**:
   - Clearly state the catastrophic failure condition (e.g., 42.4s latency stall, 48 GB RAM bloat).
   - Pair it directly with the surgical architectural solution (e.g., scoped conditional feeder rule syntax).

---

## 💎 Stage 2: Programmatic Asset Forge (Zero Slop)

1. **Strict Prohibition on AI Clipart & Emojis**:
   - ❌ Never use DALL-E/Midjourney raster illustrations, cartoonish glowing cubes, or emojis.
   - ✅ Build 100% native React/SVG components with parameterized props.

2. **Pristine White Pop-Out Chassis (`#FFFFFF`)**:
   - Place all primary dashboards/consoles in pure white ceramic containers (`#FFFFFF`) with deep occlusion drop shadows:
     `boxShadow: '0 50px 120px -20px rgba(0, 0, 0, 0.95), 0 20px 50px -10px rgba(0, 0, 0, 0.6)'`
   - Achieves a **100:1 contrast pop** against dark studio obsidian floors (`#0B0C0E`).

3. **Tactile Micro-Density Suite**:
   - `ChassisFrame.tsx`: Unibody container with corner tick marks (`┌ ┐ └ ┘`) and dual-ring status LEDs.
   - `DimensionTopologyTree.tsx`: Multi-tier dimension hierarchy inspector with multiplication callouts.
   - `BitLatticeGrid.tsx`: Dynamic 16×8 bit matrix visualizing memory traversal waste.
   - `CircuitConduit.tsx`: 45° chamfered bus traces with animated kinetic photon pulses.
   - `TelemetryGauge.tsx`: Calibrated 3-tier measurement dial with tabular digits.
   - `HexRegisterDump.tsx`: High-density live memory address telemetry stream.

---

## 🎯 Stage 3: Spatial Choreography & Eye-Trace Placement

1. **Two-Column Optical Balance (`1.0fr : 1.2fr`)**:
   - **Left Column**: Structural Anchor (Hierarchy Trees, Rule Syntax, Register Streams).
   - **Right Column**: Dynamic Telemetry (Live KPI Tickers, BitLattice Grids, Gauges, Action Buttons).

2. **Guided Micro-Target Waypoints**:
   - Use `interpolateCameraWaypoints()` with cubic-bezier deceleration:
     `Easing.bezier(0.22, 1, 0.36, 1)`
   - Smoothly zoom to 1.30x - 1.35x and pan directly to the active speaking point.

3. **Selective Defocus & Dimming**:
   - Inactive sub-cards automatically dim to 35% opacity with a soft 1.5px blur (`getSelectiveFocusStyle(false)`).
   - Directs 100% of viewer foveal attention to the active metric.

4. **Zero Viewport Clutter**:
   - Completely eliminate extraneous viewport header bars, floating logos, and watermark clutter.
